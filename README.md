# MechZen Phase 2 Upgrade Bundle

This bundle upgrades your project to **Phase 2** while preserving your exact styling, layout, and visual design.

## What's Included:
1. **`mechzen.html`**: The fully updated frontend template featuring asynchronous batch uploads, live status badges, and RBAC supervisor review actions.
2. **`evaluate.py`**: The evaluation script to compute the confusion matrix and verify 100% defect recall on sample images.

## How to Apply:
1. Extract this zip file into your root project folder (`hackathon-project/`).
2. Replace or update your existing `mechzen.html` and `evaluate.py` files with the ones in this folder.
3. Run your Django server (`python manage.py runserver`) or open `mechzen.html` directly in your browser.
